# 3-bit-flip-flop (CtD) figures. These require the external
# Computation-through-Dynamics toolkit, installed separately:
#
#   https://github.com/snel-repo/ComputationThroughDynamicsToolkit
#
# Install that toolkit into its own Python 3.10 environment (it pulls in a
# compatible torch / numpy / matplotlib), then set CTD_TOOLKIT_DIR in .env and
# run the CtD scripts from that environment. The packages below are the direct
# imports of the scripts in this repo on top of the toolkit's dependencies.
#
# Tested with Python 3.10.20.

numpy
torch
matplotlib
python-dotenv        # optional: only read if a local .env is present
